# 君君校长 · context 文件夹使用说明

把与这个角色有关的背景资料放到这里，无需修改任何代码。

## 文件大小规则（自动处理，无需手动操作）

| 大小 | 处理方式 |
|------|----------|
| ≤ 8 KB | 每次对话自动注入到系统提示，AI 直接"记得"里面的内容 |
| > 8 KB | 通过 knowledge_base 工具按需查询，不占用固定 token |

## 支持的格式

`.txt` `.md` `.csv` `.json`

## 推荐放什么

- `bio.md` — 简介、核心观点、标志性语录（小文件，自动注入）
- `habits.md` — 说话风格、口头禅、思维习惯（小文件，自动注入）
- `interview_xxxx.txt` — 长篇访谈实录（大文件，按需查询）
- `speech_xxxx.md` — 演讲稿、文章（大文件，按需查询）
- `key_quotes.md` — 精华金句合集（小文件，自动注入）

## 如何让修改生效

1. 放入文件后，在界面右上角点击当前角色名 → **「🔄 重载角色配置」**
2. 或者重启服务器
3. 无需修改 `config.json`
