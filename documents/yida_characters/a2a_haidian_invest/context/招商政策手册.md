# 海淀区招商引资核心政策手册（2024年版）

> 本文档供海淀区招商局智能体作为知识背景使用，基于中关村科学城管委会及海淀区相关政策文件整理。

---

## 一、区域招商 — 落地资质与奖励政策

### 1.1 重点引进领域（四大主赛道）
- 人工智能：大模型、具身智能、AI基础设施
- 生物医药：创新药、高端医疗器械、CRO/CMO
- 集成电路：EDA工具、先进封装、芯片设计
- 智能网联汽车：自动驾驶算法、车路协同、智能座舱

### 1.2 企业落地基本门槛
| 类型 | 条件 |
|------|------|
| 科技型企业 | 年营收≥5000万元，或已完成B轮及以上融资 |
| 独角兽/潜在独角兽 | 估值≥10亿元 |
| 国家高新技术企业 | 在海淀注册并有研发团队 |
| 规模以上企业 | 年营收≥2000万元首次纳统 |

### 1.3 落地奖励标准
- **企业注册奖励**：符合条件的企业迁入或新设，最高100万元一次性奖励
- **规模以上纳统奖励**：30万元一次性支持
- **研发投入补助**：上一年度研发投入达到一定规模且同比增长≥10%，最高100万元
- **成果转化奖励**：通过"中关村国际前沿大赛"等落地项目，最高50万元支持

### 1.4 办公空间支持
- 中关村科学城核心区域提供创新工场优惠租金（部分项目享受5折优惠）
- 重点引进企业可申请海淀区产业园区优先选址服务

## 二、科研支持 — 高校与科研机构合作政策

### 2.1 联合实验室支持
- **政策**：支持企业与清华、北大、中科院等单位共同设立联合实验室或博士后工作站
- **支持方式**：资金配套（最高200万）+ 场地协调 + 人才引进绿通
- **申报入口**：中关村科学城管委会产学研合作服务平台

### 2.2 专精特新 / 小巨人企业扶持
| 认定层级 | 一次性奖励 |
|---------|-----------|
| 国家级专精特新"小巨人" | 50万元 |
| 隐形冠军/制造业单项冠军 | 200万元 |
| 北京市级专精特新中小企业 | 20万元 |

**附加政策**：
- 纳入政府投资基金储备库（科技人才贷、并购贷优先）
- 差异化环保监管（纳入正面清单，减少合规负担）
- 优先推荐承接政府采购项目

### 2.3 科研成果转化通道
- **"中关村开放实验室"计划**：为有产业化意向的科研团队提供验证场景、对接企业资源
- **"HICOOL全球创业大赛"**：面向全球科技创业团队，优胜项目可获海淀落地支持50万元及加速资源
- **科技中小企业研发补助**：年研发投入增长超过15%的企业，可享受研发支出15%补贴，上限500万/年

## 三、人才引进 — 海英计划详细规则

### 3.1 "海英人才"专项分类
| 类别 | 适用对象 | 主要支持 |
|------|---------|---------|
| 海英领军人才 | 院士、国家级人才工程入选者 | 安家补贴200-500万，享落户绿通 |
| 海英青年英才 | ≤35岁，在重点领域取得核心成果 | 最高100万补贴，公寓配租 |
| 海英之星（应届生） | 985/211硕士及以上，就职于独角兽或国家级专精特新企业 | 青年公寓配租（6折）或租房补贴2万元/年 |

### 3.2 外埠人才引进条件
- 在申请单位工作满2年（或满试用期6个月以上的关键岗位人员）
- 无刑事犯罪记录，年龄一般不超过45岁（特殊情况可放宽）
- 持有国家认可学历学位（国内本科以上或海外等效学历）
- 申报途径：用人单位集中统一申报，"需求摸底+申报核准"模式

### 3.3 留学回国人员引进
- 在申请单位实际工作满3个月
- 持境外高校本科及以上学历（认证机构：教育部留学服务中心）
- 重点紧缺岗位可不受时间年限限制

### 3.4 申报渠道
- **微信公众号**：智汇海淀
- **网络平台**：海淀区专项资金网上申报统一入口
- **线下服务**：中关村人才大厦一站式服务窗口
- ⚠️ 全程不委托任何第三方中介，不收取任何费用
