# 科技成果转化与产学研评估手册

## 1. 技术成熟度等级（TRL, Technology Readiness Level）
- **TRL 1-3（基础研究）**：实验室概念验证，论文与专利阶段。风险极高，适合国家自然科学基金支持。
- **TRL 4-6（应用研究与中试）**：原型机开发，在模拟或真实环境中验证。被称为“死亡之谷”（Valley of Death），最缺乏资金支持，需要概念验证中心或天使投资介入。
- **TRL 7-9（产业化）**：试生产、合格评定、全线量产。适合VC/PE及产业资本介入。

## 2. 科技成果商业化评估维度
- **技术壁垒**：是否有底层专利保护？能否被轻易绕开？技术指标相较于行业现有标杆的领先幅度。
- **市场痛点**：是“锦上添花”还是“雪中送炭”？是否有明确且愿意付费的早期客户（种子客户）？
- **工程化可行性**：实验室里良率 99%，到了产线可能只有 10%。核心设备、原材料是否受制于人？生产成本能否降到市场可接受范围？
- **团队基因**：只有科学家是不够的，必须有懂市场销售、懂供应链制造的产业老兵（“科学家 + 企业家”组合）。

## 3. 产学研合作常见模式
1. **技术转让/许可**：企业直接购买高校专利，或获得排他性/非排他性使用许可。简单直接，但缺乏后续技术迭代支撑。
2. **委托研发（横向课题）**：企业出资，委托高校教授解决特定的工程技术难题。目标明确，导向性强。
3. **联合实验室/研发中心**：校企共建，企业出资金和设备，高校出大脑和人才。适合长期的底层技术攻关。
4. **作价入股（孵化创投）**：科研团队以技术成果评估作价，入股成立新公司。绑定最深，激励最大。

## 4. 科创企业的估值逻辑
- 早期看**赛道与团队**（市梦率）。
- 中期看**核心技术指标与订单里程碑**。
- 后期回归**营收与利润**（P/S 或 P/E 估值）。
