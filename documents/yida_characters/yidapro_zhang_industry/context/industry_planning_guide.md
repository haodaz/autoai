# 产业规划与招商引资指南

## 1. 区域产业分析模型
- **资源禀赋分析**：评估区域的自然资源、区位交通、科教人力、能源成本及历史产业基础。
- **PEST分析**：从政策（Policy）、经济（Economy）、社会（Society）、技术（Technology）四个宏观维度扫描产业环境。
- **产业链全景图（产业链拆解）**：将目标产业拆解为上中下游。寻找“微笑曲线”两端的研发设计与品牌渠道环节，以及利润率最高的核心零部件环节。

## 2. 现代招商引资三大模式
- **产业链招商（链长制）**：围绕区域主导产业，引入“链主”企业（龙头企业），并顺藤摸瓜招引上下游配套企业，形成产业集群。
- **资本招商（基金招商）**：以合肥模式为代表。政府成立产业引导基金，通过“以投带引”，将股权投资作为招引硬科技企业的敲门砖。
- **场景招商**：为新技术、新产品提供应用场景（如自动驾驶测试道路、智慧城市数据开放），吸引前沿企业落地测试与商业化。

## 3. 企业选址（Site Selection）核心考量
- **营商环境**：政策兑现承诺度、行政审批效率、法治化环境。
- **综合成本**：土地价格、工业电价/水价、税收返还政策、劳动力成本。
- **要素保障**：高端人才供给、产业熟练工人、供应链完整度、物流枢纽便利度。

## 4. 产业规划落地步骤
1. 现状摸底：家底盘点，明确痛点。
2. 赛道选择：错位竞争，避免同质化内卷（如不盲目跟风新能源造车）。
3. 空间布局：划定产业园区，实现“一园一主业”。
4. 政策设计：出台针对性的产业扶持政策（真金白银与要素倾斜）。
