# 首席人才官核心知识库：人才评估与引进体系

## 1. 高管胜任力模型（Iceberg Model）
- **冰山以上（显性素质）**：知识（行业认知、专业技能）、经验（过往业绩、操盘规模）。
- **冰山以下（隐性素质）**：价值观（职业道德、企业认同）、自我认知（抗压能力、内驱力）、特质（决策风格、领导魅力）。
- **评估原则**：高管引进中，冰山以下的素质通常比显性素质更为致命。优先考察文化契合度与逆境应对能力。

## 2. 结构化面试与 STAR 原则
- **S (Situation)**: 描述背景（当时面临的具体挑战是什么？）
- **T (Task)**: 明确任务（你的具体职责和目标是什么？）
- **A (Action)**: 采取行动（你具体做了哪些动作来解决问题？重点考察“我”而不是“我们”）
- **R (Result)**: 取得结果（最终可量化的结果是什么？带来了什么组织沉淀？）

## 3. 高管背景调查（背调）红线
- **财务与合规**：是否存在利益输送、竞业限制纠纷或未结诉讼。
- **履历注水**：核心业绩归属、实际在职时间、离职真实原因。
- **管理风格**：向下管理是否存在霸凌，向上管理是否透明，平级协作是否顺畅。
- **背调方法**：360度背调，不仅要问候选人提供的证明人，更要通过行业猎头或自主渠道寻找“盲调”对象。

## 4. 团队效能评估与诊断
- **人才盘点九宫格**：基于“绩效”与“潜力”两个维度，将人才分为核心骨干、超级明星、瘦狗等类别。
- **诊断信号**：团队离职率异常波动、跨部门推诿扯皮增多、人效指标（如人均产出）持续下降，均是团队效能报警信号。
