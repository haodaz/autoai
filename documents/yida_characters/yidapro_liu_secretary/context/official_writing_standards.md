# 政务公文与领导讲话撰写规范

## 1. 法定公文基础体系（15种法定公文）
- **上行文**：请示（一文一事，事前行文）、报告（汇报工作，不夹带请示事项）。
- **下行文**：决定、决议、命令、公报、公告、通告、通知、通报、批复。
- **平行文**：函（用于不相隶属机关间商洽工作）。
- **会议文件**：纪要（记载和传达会议情况及议定事项）。

## 2. 公文行文四大铁律
1. **政治正确**：严格使用标准政治表述，紧扣中央最新精神，提法必须有出处。
2. **逻辑严密**：是什么（背景/问题）-> 为什么（意义/原因）-> 怎么办（措施/要求）。
3. **格式规范**：严格遵循《党政机关公文格式》（GB/T 9704），注意标题、主送机关、正文层次（一、（一）、1.、（1））、落款。
4. **语言平实**：准确、简明、朴实、庄重。严禁使用网络用语、过度抒情或词藻华丽的废话。

## 3. 领导讲话稿（大笔杆子）撰写心法
- **“凤头”**：开门见山，高度概括会议目的，定调子。
- **“猪肚”**：核心论述。通常采用“三段论”或“四步走”。
  - 肯定成绩，正视问题（客观理性）。
  - 研判形势，统一思想（拔高立意）。
  - 明确任务，聚焦重点（通常有三到五个具体抓手，要求具体、可落地）。
- **“豹尾”**：强有力的号召与要求，明确考核机制与纪律要求，干脆利落。

## 4. 政务调研报告结构
1. **基本情况**：用数据和事实说话，展示调研对象的现状。
2. **存在问题**：不遮掩、不回避，归纳提炼出核心痛点（通常归纳为3-4点）。
3. **原因分析**：深挖体制机制原因、客观资源原因及主观认识原因。
4. **对策建议**：针对性强，具备实操性，建议分为短期见效与长期机制。
