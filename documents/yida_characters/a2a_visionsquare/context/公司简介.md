# 平方创想（VisionSquare）公司简介

## 一、公司定位

**平方创想教育科技(北京)有限公司（VisionSquare）** 是一家数据科技型企业，立足高等教育，深耕和赋能高知识密度和高专业需求的**「教育-科技-人才一体化」**行业。

核心愿景：与生态合作伙伴一起打造**"可信任"数智化服务工具与资源**，为行业用户赋能，打造可信任的行业服务体系。

---

## 二、核心技术基础设施

### Learning Graph（学习图谱）
- 覆盖 **154 个国家**，超 **15 万人才**数据
- 收录 **6 万名顶尖学者** 档案
- 全球 **1600+ 高校**数据
- 连通 WOS、Scopus、Microsoft Academic 等国际学术数据库
- 与 NSF、NIH 等科研基金机构数据打通

### Knowledge Graph（知识图谱）
- 专业领域知识结构化建模
- 支持真知识（True Knowledge）与真数据（True Data）的融合
- 为 AI 提供可验证、可追溯的知识来源（解决幻觉问题）

### Trusted Implementation 信任机制
- Authenticity（真实性验证）
- True Value（价值发现）
- 类 FICO Score 的人才信用评分体系

## 三、产品矩阵

以「工作台 + 智能体」为产品形态，构建多角色、多场景的数智化服务开放平台。

### 主要产品线

| 产品 | 定位 | 主要用户 |
|------|------|---------|
| **知己（ZhiJi）** | AI 社交机器 / Agentic AI 生态 | ToC + ToB |
| **申请方（ApplySquare）** | 国际教育招生管理工作台 | 高校招生官、中介机构 |
| **一答（YiDa）** | 大学治理 Agentic AI 平台 | 高校管理者 |
| **极转通（JiZhuanTong）** | 全球人才转化与对接 | 人才机构、政府 |
| **FutureSquare** | 留学规划与未来路径导航 | ToC 学生 |
| **方略研究院（SquareStrategics）** | 高等教育数据研究与咨询 | 高校、政府、基金 |
| **Polarise** | 产业洞察与评估工具 | B 端企业 |

### 知己（ZhiJi）核心能力

- **三种 AI 模式**：陪伴助手、任务委托（Manager-Worker）、A2A Swarm 群体智能
- **Agentic 架构**：基于 MCP Sub-Agents、Handoff、Context Relay 实现 AI 自主协作
- **5 层管控体系**：System Prompt → Skill → SOP → Factory Inspection → 角色 config.json
- **AI Harness 协调层**：多智能体任务分配与结果合并

## 四、商业模式与合作方向

### 目标客户
- **ToC**：留学生、职场人才、大学生
- **ToB**：高校、人才机构、猎头公司、企业 HR
- **ToG**：政府人才主管部门、科技园区、引才办

### 主要合作形式
1. **API / MCP 工具接入**：将平方创想的知识图谱、人才搜索、AI 评估能力以 API 形式开放给合作伙伴
2. **白标合作（OEM）**：将工作台产品贴牌输出给高校或大型机构
3. **数据授权**：Learning Graph 数据向科研机构、政府部门开放
4. **联合研发**：与高校 AI 实验室、研究机构共建特定场景解决方案
5. **生态入驻**：欢迎第三方智能体、工具、服务接入知己 Agentic 生态
