# 数据情报挖掘与宏观经济指标辞典

## 1. 核心宏观经济指标（经济的仪表盘）
- **GDP（国内生产总值）**：综合国力指标。重点关注同比增速与环比增速，以及三次产业结构的占比。
- **CPI（居民消费价格指数）**：衡量通胀的核心指标。温和上涨（2%-3%）是健康标志，负增长则警惕通缩风险。
- **PPI（工业生产者出厂价格指数）**：反映工业企业产品出厂价格变动，是上游利润的晴雨表。通常 PPI 会向 CPI 传导。
- **PMI（采购经理指数）**：50% 为荣枯线。高于 50% 经济扩张，低于 50% 经济收缩。是极佳的前瞻性先行指标。
- **M1 与 M2 增速差（剪刀差）**：M1反映企业活期存款，M2反映广义货币供应。M1增速大于M2，说明企业预期乐观，投资意愿强；反之则说明资金在空转或定期化。

## 2. 数据分析核心逻辑陷阱
- **相关性不等于因果性**：例如“冰淇淋销量高的时候，溺水人数也多”，两者高度相关，但原因是“夏天到了”，而非吃冰淇淋导致溺水。
- **幸存者偏差**：只关注成功企业的数据，忽略了沉默的失败样本，导致分析结论产生致命偏差。
- **基数效应**：当去年同期数据极低时（如疫情封控期间），今年的同比增速会显得异常夸张，必须剥离基数效应看真实两年复合增速。

## 3. 产业数据挖掘模型
- **时间序列分析**：看趋势（Trend）、季节性（Seasonality）与周期性（Cyclicality）。
- **横向对标分析（Benchmarking）**：跨区域对比（如杭州与成都的数字经济规模对比）、跨企业对比。
- **漏斗分析**：常用于业务转化与招商项目落地分析（线索获取 -> 意向洽谈 -> 签订协议 -> 资金到位 -> 投产达效），找出流失率最高的环节。

## 4. 数据可视化的原则
- 表达时间趋势用**折线图**。
- 表达构成占比用**饼图/瀑布图**。
- 表达项目对比用**柱状图/条形图**。
- 寻找多变量相关性用**散点图**。
